Я владею широким спектром инструментов для backend-разработки. Вот ключевые:

## 🚀 Проекты

Вот некоторые из моих ключевых проектов. Я расширил список, чтобы показать разнообразие опыта – от соцсетей до инструментов анализа и безопасности. Каждый проект демонстрирует мои навыки в backend.

- **Bazier.live** 🌐  
  Социальная сеть со свободой слова. Разработал backend на Node.js/Express с MongoDB, интегрировал аутентификацию, чаты и контент-модерацию. Работал с AWS для хостинга.  
  [Ссылка на сайт](https://bazier.live) | Технологии: Node.js, Express, MongoDB, AWS  

- **TIC-ID Analyzer** 🔭  
  Анализатор TIC-идентификаторов от NASA с последующим анализом из множественных каталогов (TESS/Kepler) и классификацией экзопланет с использованием CNN. Обработал данные из API, добавил кэширование для ускорения.  
  [Ссылка на репозиторий](https://github.com/root3315/TIC-id) | Технологии: Python, Lightkurve, TensorFlow, API NASA  

- **Algorithm сжатия для социальной сети** 📦  
  Алгоритм сжатия данных для оптимизации хранения и передачи контента в соцсетях. Реализовал на Python с использованием библиотек вроде snappy, снизил объем данных на 40%.  
  [Скрыт](https://github.com/root3315/) | Технологии: Python, Snappy, NumPy  

- **Telegram Bot для регистрации на турнир** ♟️  
  Бот для регистрации на шахматный турнир. Добавил инлайн-кнопки, асинхронные запросы и интеграцию с базой данных.  
  [Ссылка на репозиторий](https://github.com/root3315/Tg_bots.git) | Технологии: Python, Aiogram, SQLite  

- **Асинхронный сканер субдоменов и уязвимостей** 🛡️  
  Инструмент для сканирования доменов на уязвимости с использованием Nmap и httpx. Добавил сохранение результатов, лимит скорости и Telegram-интерфейс.  
  [Временно скрыт](https://github.com/root3315/) | Технологии: Python, Asyncio, Nmap, Httpx  

- **OLMA Project** 📱  
  Разработка мобильного приложения/сервиса API. Backend на PHP/Node.js с фокусом на социальные функции.
